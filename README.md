# Khaled Portfolio Website

This project is a personal portfolio website built using **Jekyll** and hosted via **GitHub Pages**.

It is designed to present a developer’s profile, projects, and skills in a clean and structured way.

## Overview

The website automatically generates content from the GitHub profile and repositories, including:

- Personal profile section
- List of projects and repositories
- Interests and skills
- Blog posts (optional)

## Technology Stack

- Jekyll (Static Site Generator)
- GitHub Pages (Hosting)
- GitHub API (Dynamic content)

## Features

- Responsive and simple design
- Auto-generated project listing from GitHub
- Easy customization through `_config.yml`
- Support for themes (light/dark)
- Social media integration

## Customization

All main settings can be controlled from the `_config.yml` file, including:

- Layout style (sidebar or stacked)
- Theme (light or dark)
- Projects display settings
- Social media links
- Topics and interests

## Deployment

The website is deployed using GitHub Pages.  
Once changes are pushed to the repository, the site is automatically updated.
